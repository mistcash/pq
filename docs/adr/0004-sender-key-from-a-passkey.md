# The Sender Key comes from a passkey, so a quantum attacker can't re-derive it

A wallet signature (ADR-0002) falls to a quantum attacker: registering puts the wallet's public key on-chain, and a recovered private key re-signs the fixed message deterministically (#44). So the Sender Key is H(a passkey's PRF output), from a passkey Join makes; its PRF secret never leaves the passkey and no public key reveals it, and the wallet now only joins. We chose it over a password, which anyone holding the signature could guess offline against the on-chain User Key, and over a recovery phrase, a backup chore. The costs: every User re-registers and existing Channels are orphaned, browsers and passkey managers without PRF can't join, a passkey only works on the site's domain, and losing it loses every Channel.
