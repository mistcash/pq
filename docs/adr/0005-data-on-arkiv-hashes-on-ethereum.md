# User Keys and Channels live on Arkiv, and Ethereum keeps only their keccak256 hashes

Glamsterdam's EIP-8037 charges about 1,530 gas for each new byte of state on Sepolia, so storing an 800-byte User Key or a Channel's 39 words cost millions of gas. Now PqMsg still takes the whole User Key or Channel in calldata, so it can check the length and the proof, but stores only its keccak256, the cheapest hash on the EVM. The Fixed Sender writes the data to Arkiv as one entity, keyed by that hash, with Arkiv's longest lifetime, about 182 days (we wanted a year, which Arkiv doesn't allow). Readers fetch the data from Arkiv and drop anything that doesn't hash to a value on Ethereum, so Arkiv only has to keep the data available, not keep it correct.

The Fixed Sender owns every entity, so users need no Arkiv funds, and a Channel's entity doesn't show who opened it. A recipient's User Key Hash is still read over Anon-RPC, but the key itself comes from Arkiv by that hash, so Arkiv's RPC can see whose key you fetched. We kept messages on Ethereum: they are two words each, and moving them would make Arkiv's availability decide whether a message can be read.

The costs: users trust Arkiv to keep the data available, and it expires after about 182 days unless the Fixed Sender extends it. The User Key and Channel only stay public on Ethereum as calldata in old transactions. Readers make one more network round trip. Hashes are keccak256, not the Poseidon2 the circuit uses (ADR-0001), as nothing in the circuit needs them.
